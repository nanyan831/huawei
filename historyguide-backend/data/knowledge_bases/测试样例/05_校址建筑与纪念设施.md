## 5. 校址变迁与重要建筑

### 5.1 校址线索

| 时期／地点 | 历史关系与介绍边界 | 来源 |
| --- | --- | --- |
| 严氏家塾、南开洼 | 属南开教育体系早期发展；大学成立之初使用南开学校相关校舍 | [S01]；Z19-01 |
| 天津八里台 | 1923年迁入；1946年返津复校的核心地点，现地址为卫津路94号 | [S02][S06] |
| 长沙 | 1937年临时大学联合办学地点 | [S02] |
| 昆明及云南相关地点 | 1938年后西南联大及南开相关教研活动所在地；具体院系、阶段可能不同 | [S02][S25] |
| 重庆沙坪坝 | 战时南开经济研究所的重要办学研究地点，不能遗漏 | [S52] |
| 天津迎水道 | 与1994年天津对外贸易学院并入有关；2015年相关学生迁往新校区，属历史校区线索 | [S04][S68] |
| 天津泰达 | 1998年合作签约、1999年揭牌、2000年前后建设运行等应分开讲；现地址宏达街23号 | [S04][S06][S69] |
| 天津津南 | 2015年启用，现地址海河教育园区同砚路38号 | [S05][S06] |

### 5.2 建筑与纪念设施条目

| 编号 | 名称 | 历史背景、人物及可核对介绍 | 来源 |
| --- | --- | --- | --- |
| B01 | 八里台秀山堂旧址／原建筑 | 1923年建成，早期行政及文商教学中心，以捐资人李纯字“秀山”命名；1937年被毁。旧址后续利用与津南复建楼须分开 | [S26][S29] |
| B02 | 八里台思源堂 | 1923年始建、1925年投入使用，原为科学馆；洛克菲勒基金会与袁述之捐建；战时受损后保存，并非完全毁灭后无原物 | [S26][S28] |
| B03 | 八里台木斋图书馆历史建筑 | 卢靖捐建，1928年启用，1937年严重毁损；后来的重建、旧址建筑与津南复建馆应按阶段辨认 | [S65][S28]；Z19-12 |
| B04 | 八里台主楼 | 1962年建成；长期承担教学科研与集会功能，是校园代表性建筑 | [S27] |
| B05 | 文中馆 | 原理科图书馆，1958年建成；2018年命名为文中馆 | [S27][S75] |
| B06 | 海冰楼 | 前身是1952年建成的大礼堂，早期兼有饭厅功能；2016年校友捐资支持改造，2018年起扩建；2019年百年校史展设于一楼 | [S27][S07] |
| B07 | 马蹄湖与周恩来纪念碑 | 1979年建校60周年时在湖心岛立碑；纪念碑文字与杨石先所书碑文可联系周恩来与母校的关系 | [S38] |
| B08 | 主楼前周恩来塑像 | 1989年10月17日揭幕；与湖心岛纪念碑是不同纪念设施 | [S27][S04] |
| B09 | 校钟 | 今日所见为1997年重铸纪念钟；高1.937米、60枚校徽纹样与1937年毁校及六十周年纪念有关 | [S37] |
| B10 | 西南联大纪念碑 | 2007年纪念联大建校70周年，由历史系77级校友捐资，依昆明原碑复制；不是1946年昆明原碑整体迁来 | [S39] |
| B11 | 严修、张伯苓纪念空间 | 张伯苓铜像1986年揭幕、1989年移入中心花园；严修铜像1992年揭幕 | [S04] |
| B12 | 宁园及陈省身相关空间 | 宁园承载陈省身晚年在南开生活、研究的记忆；与省身楼、数学所等共同构成数学文化线索 | [S48]；Z19-13 |
| B13 | 迦陵学舍 | 与叶嘉莹晚年讲学、研究和居住相关；其荷花情结有本人文章佐证 | [S58]；Z19-13 |
| B14 | 津南历史纪念区三栋复建楼 | 秀山堂、思源堂、木斋馆于2016年举行复建奠基，2019年工程完工报道发布；属于新址复建 | [S28] |
