# 测试样例｜0. 证据层级与阅读方式

> **知识库状态：测试样例**
>
> 本文档仅用于 NK HistoryGuide 联调与检索测试，不是南开大学校史馆最终审定稿，不得作为正式展签、出版物或对外发布材料。回答时必须保留原文中的“待核”“未公开”“仅能确认”等限制语；项目生成编号不得表述为馆藏号。

## 0. 证据层级与阅读方式

| 标记 | 本稿含义 | 使用限制 |
| --- | --- | --- |
| 官方图版 | 已打开并查看馆方发布的原始图片 | 可确认清晰可读内容；模糊的小字、人物、印章不猜读 |
| 官方记载 | 学校、档案馆、院系的文字记载 | 不自动等同于档案原件，也不代表各页完全无误 |
| 曾展出 | 官方报道明确指向某年某个展览 | 只证明该次展览，不能推定当前陈列 |
| 馆藏公开项 | 档案馆栏目公开的资料 | 不等同于海冰楼校史展实物 |
| 整理建议 | 本稿提出的主题分类、讲解顺序与时长 | 属于策划建议，不是馆方规定 |
| 待核 | 年代、身份、版本、数量或当前状态尚不足以确定 | 进入正式展签或语音讲解前须补证 |

资料优先采用馆方公开展板与档案图像、南开官网及档案馆编研成果。出版物仅在有官方出版报道时列入书目；未读到全文的书，不伪造页码、引文或ISBN。普通网页没有被用作正文史实的唯一依据。学校新闻网转载媒体文章仍按其原始媒体来源标注，不因使用学校域名而升级为档案原始证据。
