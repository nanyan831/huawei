## 4. 校训、校歌、公能精神与文化

| 项目 | 核验后的说明 | 来源 |
| --- | --- | --- |
| 校训 | **允公允能，日新月异**。1934年公布；本次检得的2024年公布章程亦明确载明 | [S30][S31，第6条] |
| “公” | 结合学校官方解释，指向公共责任、爱国爱群与服务社会的价值取向 | [S30] |
| “能” | 指能够承担社会责任的实际能力；讲解时须与“公”的价值要求一起解释 | [S30] |
| 日新月异 | 强调持续更新与进步；官方解释将其文化渊源联系到《大学》中的日新思想 | [S30] |
| 公能教育 | 章程将公德、能力与创新人才培养结合，不能只解释成“成绩好、技术强” | [S31，第7条] |
| 办学宗旨 | “知中国，服务中国”；与调查社会、经济研究、化工实践相互印证 | [S06][S52]；Z25-04 |
| 学校传统 | 官网概括为“爱国、敬业、创新、乐群” | [S06] |
| 爱国三问 | 1935年张伯苓提出有关中国人身份、爱国与希望国家进步的三个问题；完整原文宜从官方展板核读 | [S02]；Z25-05 |
| 校歌形成 | 官方校史文记载：1917年留日学生张蓬仙倡议，1918年底张伯苓请孙润生审定，1919年春确定；曲调借鉴《O Christmas Tree》 | [S32] |
| 校歌讲解 | 以天津地域、精神品格和进取愿景为主线；白河是海河旧称。全文和曲谱应通过官方页面核对，本稿不擅自指定唯一词作者 | [S32] |
| 校训字体 | 中文标准字取材于吴玉如1962年所书张伯苓夫妇墓碑碑文拓片，经标准化处理 | [S30] |
| 校名字体 | 中文校名标识采用毛泽东1950年手书 | [S31，第84条] |
| 校徽 | 核心为八角星形；2004年启用新校徽；“1919”指大学创建年 | [S33] |
| 徽志与徽章 | 章程区分圆形八角星徽志和长方形证章，二者不宜混称为同一图形 | [S31，第85条] |
| 校色 | 青莲紫，又称南开紫；具体色值应从学校视觉识别文件取得，不在此猜测RGB或十六进制色号 | [S31，第87条][S34] |
| 校旗 | 青莲紫底，中央为白色手书校名 | [S31，第88条] |
| 校庆日 | 10月17日；与1919年9月25日开学不是同一事件 | [S31，第89条][S02] |
| 镜箴／容止格言 | 通过整洁仪容、端正姿态和平和举止进行日常养成教育。公开报道对制定者的归属存在差异，参见第9节 | [S35][S36] |
| 体育传统 | 早期南开重视运动与身体教育；“奥运三问”与1935年“爱国三问”属于不同语境 | Z25-23、24；[S17] |
| 荷花文化 | 校色阐释、马蹄湖环境和叶嘉莹自述均与荷花相联系；不宜据此擅称荷花为经章程确定的“校花” | [S34][S58] |
