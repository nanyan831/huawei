## 9. 易混淆信息、来源差异与处理原则

| 问题 | 公开资料中的证据 | 本稿如何处理 |
| --- | --- | --- |
| 首届96人与108人 | 官网沿革及大事记列录取96人；2025年展板Z25-03写108名首届学生 | 并列保留。可能涉及时间点或统计对象差异，但未获解释，不自行认定原因；正式展签请核首届注册表及编研说明。[S01][S02][S17] |
| 开学日与校庆日 | 1919-09-25开学；10-17为校庆；成立纪念大会在11-22 | 以事件分别标日期，不写“1919-10-17首次开学”。[S02][S31] |
| 大学百年与系列学校百年 | 1904是系列学校奠基，1919是大学成立；2004校徽更新对应系列学校百年 | 不把2004年写成南开大学百年校庆。[S01][S33] |
| 百年展实物总数 | 开展报道写“五十多种近百件”；后续侧记用“百余件” | 保留不同报道口径，不给虚构精确总数、不据此计算覆盖率。[S07][S08] |
| 展板、展品与馆藏 | 官方展板可以是文献、照片、实物的复制图像 | 必须区分原件、复制件、图片和场景装置；“网页出现”不等于“馆内原件”。[S10][S17][S19] |
| 校史展与周恩来特展 | 两者都曾在海冰楼举办，但时间、策展主题和主办信息不同 | 不能将2021年特展中的所有对象默认列为2019年百年展展品。[S07][S24] |
| 原思源堂与津南复建堂 | 官方建筑资料与复建报道区分八里台存留建筑及新址复建楼 | 禁止写成三栋旧建筑整体迁移至津南。[S26][S28] |
| 秀山堂建筑年代与题名活动 | 大事记确认1923年已举行首届毕业典礼；部分文章涉及1924年铜像揭幕等活动 | 建筑采用1923年；落成、迁校、铜像揭幕不是同一日期。[S02][S29] |
| 镜箴作者与订立者 | 媒体及《党的文献》转载强调严修书写或撰写；学院新闻称张伯苓订立 | 用“南开传统容止格言”作为稳妥概括；书写者、倡导者、制度推行者分开核对，不凭单篇活动报道排除其他角色。[S35][S36][S73] |
| 校歌作者 | 官方校史文章清楚记载倡议、组织与审定过程，但本次未取得署明完整词曲责任的原版乐谱 | 不据网上传说指定唯一作词人；曲调来源与歌词责任分开。[S32] |
| 旧校钟来历 | 爱国主义教育基地介绍部分来历时使用“据说”等保留措辞 | 本稿重点收录1997重铸事实，不把旧钟的传说性来历当定论。[S37] |
| 联大成就归属 | 西南联大由三校共同组成，师生亦有不同原校背景 | 不把联大全部人才、论文、诺贝尔奖等全部归算为南开单校成果。[S02][S25] |
| 泰达成立年份 | 大事记列1998签约、1999揭牌；泰达学院文称2000建立 | 分阶段叙述；若需要唯一“成立日”，请以建院批复和校方正式年表核定。[S04][S69] |
| 官方页面也可能有编辑问题 | 《抗战时期的南开记忆》从军部分保留了提醒进一步核查的括注；部分机构及年代介绍亦存在简化 | 不把该处未经定稿的分期直接当权威结论；本稿人物事迹采用可对应图版及其他官方材料交叉使用。[S25][S17] |
| 历任校长年份的细节差异 | 杨石先人物页列第二阶段校长任期始于1979；大事记在1978年12月已列其任校长 | 区分决定、任命和任期统计可能口径；需要精确到月时核任命文件，本稿不自作裁决。[S42][S03] |
| 历史统计与今日数据 | 不同年代报道包含不同师生人数、院系数、馆藏量 | 保留统计截止期；无日期的馆藏总量不充当2026现状。[S06][S08][S09] |
