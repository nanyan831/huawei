## 2. 重要人物：身份、贡献与事件

人物的“校友”“在校就读”“毕业”“任教”“捐资人”分别记录；没有据此把所有人物都写成“南开大学毕业生”。

| 人物 | 与南开的身份／职务 | 主要贡献及相关事件 | 来源 |
| --- | --- | --- | --- |
| 严修（字范孙） | 南开教育事业奠基人、大学创建者之一，尊称校父 | 将家塾教育转向新式学校，与张伯苓创办南开；参与规划和筹资 | [S01][S44] |
| 张伯苓 | 创建者之一；1919—1948年任大学校长 | 推动公能教育、组织办学发展；1937年后参与联合办学，任西南联大常委 | [S40] |
| 凌冰 | 创校时大学部主任 | 参与早期大学管理与教育教学；不是大学创办时期的独立“第二任校长” | [S02][S46] |
| 张彭春 | 1919年大学筹备委员会主任、南开教师 | 主持起草大学计划，推动新剧；后来参与《世界人权宣言》起草，任联合国人权委员会副主席等职 | [S45] |
| 周恩来 | 南开学校学生；1919年大学首届学生；中华人民共和国首任总理 | 天津学生爱国运动重要参与者，1951、1957、1959年三回母校 | [S23][S38][S66] |
| 马骏 | 首届商科学生 | 与周恩来等参与1920年天津学生请愿；讲解可与首届名册相连 | [S02] |
| 于方舟 | 南开学生 | 参与学生运动；1924年当选中共天津地方执行委员会委员长 | [S02] |
| 黄钰生 | 南开教师，曾任文科主任、秘书长 | 参与学校教学管理；1938年任湘黔滇旅行团指导委员会主席；1946年复校典礼发言 | [S46][S02] |
| 姜立夫 | 南开数学学科创建者 | 1920年开始建设数学学科，其初创阶段常被称为“一人系” | [S47] |
| 陈省身 | 1926年入学、1930年毕业；南开数学研究所首任所长 | 几何学重要学者；1985年推动成立数学所，2000年在南开定居 | [S48] |
| 吴大猷 | 1925年入大学，1929年毕业后留校任教 | 南开早期物理学人才；与陈省身的理科学会合影是可核对的校园图像 | [S50][S49] |
| 曹禺（原名万家宝） | 1928年入南开大学政治学系，1930年转入清华 | 受南开戏剧教育影响，后成为剧作家；不能写成在南开大学毕业 | [S51] |
| 郭永怀 | 曾在南开学习的科学家 | 在南开接触物理与工程教育，并参与学术翻译；具体在校履历以专题原文及学籍记录继续核对 | [S50] |
| 何廉 | 经济研究机构创建者；1948年任代理校长 | 建设经济学科、经济研究所，参与复校 | [S41][S52] |
| 方显廷 | 经济研究所重要学者、管理者 | 参与经济调查及研究生培养；抗战时期继续开展经济研究 | [S52] |
| 陈序经 | 经济学者，曾任教务长、政治经济学院院长等 | 参与经济研究和复校；1947年兼经济研究所研究主任 | [S02][S52] |
| 宁恩承 | 南开学生、校友 | 1924年《轮回教育》引发教学内容与教育方向的反思 | [S53] |
| 张克忠 | 应用化学研究所所长 | 1932年起推动化工研究直接服务工业生产和工厂建设 | [S02][S53] |
| 傅恩龄 | 东北研究会负责人 | 从事东北地区调查和相关研究；1931年出版《东北地理教本》 | [S25，图16] |
| 陶云逵 | 边疆人文研究室主任 | 1942年起组织云南边疆社会调查 | [S02]；Z25-29 |
| 杨石先 | 化学家、教育家，曾任校务委员会主席、校长 | 建设化学学科；推动农药研究与元素有机化学研究所成立。校长任期须区别不同阶段 | [S42][S54] |
| 何炳林 | 化学系主任、高分子研究所所长等 | 发展离子交换与吸附树脂研究，相关材料服务核工业及其他行业 | [S55] |
| 陈茹玉 | 元素有机化学研究所副所长、所长等 | 长期从事有机磷化学和农药研究，推动新农药研制和人才培养 | [S56] |
| 郑天挺 | 1952年来校任历史系教授、系主任；1963年任副校长 | 清史及考据研究，建设历史学科 | [S57] |
| 申泮文 | 1935年入南开，后毕业于西南联大；南开化学教授 | 曾参加抗战，后长期教学；整理抗战史料开展教育 | [S25]；Z25-28 |
| 何懋勋 | 1935年入南开经济系的学生、抗日烈士 | 1938年在鲁西北抗日作战中牺牲 | [S25]；Z25-27 |
| 黄仁宇 | 1936年入南开机电工程系 | 后投身抗战并成为历史学家；不应误写为南开毕业生 | [S25]；Z25-27 |
| 查良铮（笔名穆旦） | 西南联大毕业生，后来任教南开 | 曾赴缅甸参加抗战，兼有诗人、翻译家与教师身份 | [S25]；Z25-28 |
| 叶嘉莹 | 1979年起在南开讲学；讲席教授、中华诗教与古典文化研究所所长等 | 推动古典诗词教学和研究；以自述可追溯她与李霁野、马蹄湖及南开的因缘 | [S58][S59] |
| 周其林及团队 | 南开化学研究团队 | 手性螺环催化剂研究获2019年度国家自然科学奖一等奖 | [S60] |
| 卢靖（字木斋） | 捐资助学者 | 捐资建木斋图书馆并捐书 | [S65] |
| 李纯（字秀山） | 捐资助学者 | 遗资支持南开办学，秀山堂以其名号命名 | [S29] |
| 周海冰、侯莹 | 南开校友、捐资人 | 支持老礼堂改造；海冰楼与侯莹厅承载此段捐资历史 | [S27] |

**历任领导扩展入口：**学校官网列有张伯苓、何廉（代）、杨石先、臧伯平、滕维藻、母国光、侯自新、饶子和、龚克、曹雪涛等历届校长页面，以及历届党委书记栏目。本稿不将任期跨越、代理职务、校务委员会主席和校长职务混作连续的一张名单。[S43]
